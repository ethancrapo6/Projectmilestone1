Purpose

The objective of this site is to discuss how internet web servers function and how these systems have developed as a result of development in the world wide web. Web Servers are essential to the Internet since they make it possible for users to access the websites and additional online data. This site will provide a review of both the base capabilities of web servers and the advancements in technology that have enabled web servers to be faster, more dependable and more secure.

What You Will Learn

Throughout this site you will discover how to make sense of the fundamental interaction between a web browser and a web server that uses the http/https protocols. In addition, you will review the historical background for web servers and discuss some of the most widely used web server platforms (Apache/Nginx/Microsoft IIS). You will then go on to look at some modern web server related technologies (virtual hosts/reverse proxies/load balancing/caching/cloud computing/content delivery networks).

Why Web Servers Matter

A web server provides users with access to the web through facilitating user requests and supplying the requested material back to the user’s web browser. Due to their increasing complexity as well as the number of users that visit websites, web servers are now capable of handling increased volumes of data and improved overall system performance. In addition, they can assist with protecting sensitive data from being compromised by malicious activity.
